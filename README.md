## Ejecución de pruebas
```python
pytest
```

## Casos de prueba
- Login exitoso
- Login fallido
- Login vacío

- Validar que el inicio de sesión fue exitoso en el Inventario
- Validar que el logo de la aplicación esté presente en el Inventario
- Validar el título de la página en el Inventario
- Validar que haya al menos un producto en la lista de inventario
- Validar el nombre y precio del primer producto
- Validar que los productos tengan nombre y precio
- Validar si es visible el carrito de compras y el filtro de productos

- Validar que el producto agregado esté presente en el carrito de compras
